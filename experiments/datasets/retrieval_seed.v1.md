# Retrieval Seed v1 — 数据卡

## 用途

这是 Memory OS 检索实验的第一份固定数据集。它只负责验证实验链路、指标实现和典型的词汇错配，不用于证明真实用户场景效果。

## 内容

- 12 篇中英文短文档，覆盖数据血缘、稀疏/向量检索、图分析、漂移、RAG 和校准。
- 7 个中文查询。
- 15 个正相关标注，等级为 1–3；3 表示直接回答，1 表示弱相关背景。
- JSON 内容的 SHA-256 由实验加载器计算，任何文档、查询或标注变化都会产生新的 dataset digest。

## 生成方式

数据是为项目手工编写的合成种子集。标注者与实现者是同一人，因此存在确认偏差；查询也比真实搜索更完整、更规范。

## 适用范围

可以用于：

- 检查 BM25、指标和 run-id 是否能稳定运行。
- 验证中英词汇错配、弱相关文档排序等已知失败。
- 为 dense、RRF 和 rerank 接口提供第一份回归测试。

不能用于：

- 对外宣称检索质量。
- 比较通用 embedding 模型优劣。
- 估计真实问题分布、长文性能或多模态效果。

## 下一版本

从真实 Memory OS 资料中抽取脱敏 query-document 对，至少包含短查询、模糊查询、跨语言查询、时间约束和应当拒答的查询。标注应由两人独立完成并计算一致性。
