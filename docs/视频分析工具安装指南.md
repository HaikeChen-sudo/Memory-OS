# 视频分析工具安装指南

## 需要什么

视频分析功能依赖两个命令行工具，放在项目 `tools/` 目录下：

| 工具 | 用途 | 大小 |
|---|---|---|
| `yt-dlp` | 下载 B站/抖音/小红书视频 | ~20MB |
| `ffmpeg` | 抽取视频关键帧 | ~50MB |

---

## 触发安装

```bash
# 在项目根目录执行
bash scripts/install-tools.sh
```

这个脚本会自动检测操作系统、下载对应版本、放入 `tools/` 目录。

---

## 不同环境的安装方式

### 本地 macOS（当前情况）

由于 GitHub 不通，脚本无法自动下载。本机已手动处理：

| 工具 | 来源 | 方式 |
|---|---|---|
| yt-dlp | `pip3 install yt-dlp` | `ln -sf ~/Library/Python/3.9/bin/yt-dlp tools/yt-dlp` |
| ffmpeg | B站客户端自带 | `ln -sf "/Users/Check/Library/Application Support/bilibili/ffmpeg/ffmpeg" tools/ffmpeg` |

这两条命令已在本地执行过，**换电脑或重装系统后需要重新执行**。

### Linux 服务器部署

服务器上 GitHub 通常也受限，改用 `apt` + `pip3`（走国内镜像）：

```bash
# 安装
pip3 install yt-dlp
sudo apt install ffmpeg -y

# 链接到 tools/
mkdir -p tools
ln -sf $(which yt-dlp) tools/yt-dlp
ln -sf $(which ffmpeg) tools/ffmpeg
```

### Docker 部署

```dockerfile
FROM node:20-slim

RUN apt update && apt install -y ffmpeg python3-pip \
    && pip3 install yt-dlp \
    && rm -rf /var/lib/apt/lists/*

# ... 其余构建步骤

# 构建后链接
RUN mkdir -p tools \
    && ln -sf $(which yt-dlp) tools/yt-dlp \
    && ln -sf $(which ffmpeg) tools/ffmpeg
```

## 验证安装

```bash
# 确认两个文件存在且可执行
ls -la tools/yt-dlp tools/ffmpeg

# 确认版本
tools/yt-dlp --version    # 应输出 2025.xx.xx
tools/ffmpeg -version     # 应输出版本信息
```

## 环境变量

视频分析还需要豆包 2.0 Lite 的 API Key，在 `.env.local` 中配置：

```env
# 如果和 1.6 Vision 用同一个 API Key，这行可以不填
DOUBAO_LITE_API_KEY=ark-xxxxxxxx

# 模型名或推理端点 ID
DOUBAO_LITE_MODEL=ep-xxxxxxxx
```

## 常见问题

**Q: 运行脚本报 `Could not resolve host: github.com`**

当前网络无法访问 GitHub。改用上面的手动安装命令（`pip3` + `apt`）。

**Q: ffmpeg 找不到**

- macOS：检查是否装了 B站客户端，路径在 `~/Library/Application Support/bilibili/ffmpeg/ffmpeg`
- Linux：`sudo apt install ffmpeg`
- 都没有：去 [ffmpeg.org](https://ffmpeg.org/download.html) 手动下载

**Q: yt-dlp 找不到**

```bash
pip3 install yt-dlp
ln -sf $(which yt-dlp) tools/yt-dlp
```
